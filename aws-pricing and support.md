# 💰 AWS Pricing Models

AWS offers different ways to pay for cloud services.

Pricing models include:

- Pay-As-You-Go
- Save when you reserve resources
- Pay less by using more

### My understanding

I only pay for the services I use instead of buying expensive servers upfront.

---

## 🆓 AWS Free Tier

AWS provides a Free Tier for new users.

Types include:

- Always Free
- 12 Months Free
- Free Trials

### My understanding

The Free Tier allows me to practice AWS services without paying, as long as I stay within the usage limits.

---

## 📊 AWS Cost Management

AWS provides tools to monitor spending.

Examples:

- AWS Cost Explorer
- AWS Budgets
- AWS Billing Dashboard

### My understanding

These tools help me track my AWS usage and avoid unexpected charges.

---

## 🛠️ AWS Support Plans

AWS offers different support plans:

- Basic (Free)
- Developer
- Business
- Enterprise

### My understanding

The Basic plan is free and includes documentation, billing support, and access to AWS Trusted Advisor checks.

---

## 🧮 AWS Pricing Calculator

The AWS Pricing Calculator helps estimate the cost of AWS services before deploying them.

### My understanding

I can estimate how much my cloud project will cost before creating resources.

---

# ⭐ Key Takeaways

- AWS follows a pay-as-you-go pricing model.
- The Free Tier is useful for learning AWS.
- Cost Explorer and Budgets help control spending.
- AWS offers multiple support plans for different needs.
- The Pricing Calculator helps estimate cloud costs.

- Cloud computing helps reduce upfront costs.
- Monitoring costs is an important cloud skill.
- AWS provides several tools to help users manage their budgets.
