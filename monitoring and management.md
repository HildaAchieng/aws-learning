# 📈 Amazon CloudWatch

Amazon CloudWatch is a monitoring service that collects metrics, logs, and events from AWS resources.

### Key Features

- Monitor resource performance
- View metrics and logs
- Create alarms
- Automate responses

### 📝 My Notes

CloudWatch helps me monitor the health and performance of AWS resources like EC2 instances.

Example metrics:
- CPU Utilization
- Memory Usage (with custom metrics)
- Disk Activity
- Network Traffic

---

# 📜 AWS CloudTrail

AWS CloudTrail records user activity and API calls made within an AWS account.

### Key Features

- Tracks account activity
- Records API calls
- Helps with security investigations
- Supports auditing

### 📝 My Notes

CloudTrail tells me **who did what and when** in my AWS account.

Example:
If someone deletes an EC2 instance, CloudTrail records:
- Who performed the action
- Time of the action
- Which resource was affected

---

# 🛡️ AWS Trusted Advisor

Trusted Advisor provides recommendations to improve AWS environments.

Categories include:

- Cost Optimization
- Performance
- Security
- Fault Tolerance
- Service Limits

### 📝 My Notes

Trusted Advisor acts like an AWS consultant by identifying areas where I can improve security, reduce costs, and optimize performance.

---

# ❤️ AWS Health Dashboard

AWS Health Dashboard provides information about AWS service events and scheduled maintenance.

### 📝 My Notes

If an AWS service experiences an outage or planned maintenance, the Health Dashboard lets me know how it might affect my resources.

---

# ⭐ Key Takeaways

- CloudWatch monitors AWS resources and applications.
- CloudTrail records activity for auditing and security.
- Trusted Advisor provides best practice recommendations.
- AWS Health Dashboard keeps users informed about service health.

---

# 🌍 Real-World Example

Imagine running an online store:

- CloudTrail = Visitor logbook showing who entered and what they did
- Trusted Advisor = Business consultant giving improvement tips
- Health Dashboard = Utility company notifying you of planned maintenance
